How do I know it worked?

After you submit a form, the robot replies on it within 1–2 minutes: ✅ Done! means the website is updated. ❌ tells you what to fix. Tap Check my updates to see all replies.

🔐 Admin Login

Paste your GitHub access key to manage the website. It is saved only on this phone/computer.

🔑 Step 1: Create my access key
  1. Tap the button above (log in to GitHub if asked).
  2. In Expiration, choose No expiration.
  3. Scroll to the bottom and tap the green Generate token button.
  4. Copy the code that starts with ghp_, come back here, paste it above and tap Login.
Other way (fine-grained key)
  1. Open github.com → Settings → Developer settings → Personal access tokens → Fine-grained tokens.
  2. Click Generate new token. Name it "Academy website".
  3. Repository access: Only select repositories → choose future-talent-Academy-jamshoro.
  4. Permissions → Repository permissions → Contents: Read and write.
  5. Generate, copy the token and paste it above.
